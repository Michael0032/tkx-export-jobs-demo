# TKX Export Jobs — demo

Stand-alone demo of the TKX vehicle export job manager (jobs, supplier quotes and PFIs, multi-job payment allocation, documents checklist, alerts, schedule, sales report, Excel export).

- **Fictitious data only.** Everything you enter is stored in your own browser (localStorage); nothing is sent anywhere. Use “Reset demo data” in the banner to start over.
- **Claude document reading (OCR / AI) is disabled in this demo.** Payment advices in MT103 / pacs.008 text or text-based PDF are still read by the built-in parser.
- **Install on iPhone:** open the link in Safari → Share → *Add to Home Screen*. **On Mac (Safari):** File → *Add to Dock*.

Open: https://michael0032.github.io/tkx-export-jobs-demo/
